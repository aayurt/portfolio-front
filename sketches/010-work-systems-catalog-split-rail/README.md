## Variant: Filterable Systems Catalog (010-work-systems-catalog-split-rail)

### Design stance
An engineering-first, filterable 2-column catalog of production systems and platforms. Replaces the cramped, vertically overflowing horizontal swipe carousel with a browsable grid that presents each project at a glance without 2D scrolling.

### Key features
1. **Interactive Domain Filter Bar:** Instant client-side filtering between `All Platforms (6)`, `Autonomous AI (2)`, `Multi-Tenant SaaS (2)`, `Fintech & Quant (1)`, and `Vedic Astrometry (1)`.
2. **Fixed-Height Visual Header:** Every card has an architectural diagram or terminal preview container (200px) that gives instant visual recognition.
3. **High-Signal Metrics Rail:** A compact 3-column metric bar highlighting latency, throughput, and reliability benchmarks (`< 50ms Dispatch`, `< 0.8s Gate Scan`, `0ms Offline Read`).
4. **Balanced Action Bar:** Standardized `[Live Demo ↗]` and `[Case Study →]` pill buttons pinned uniformly at the bottom of each card.
5. **No 2D Scroll Trap:** Everything is scrollable vertically with standard page scroll, eliminating the awkward carousel navigation.
