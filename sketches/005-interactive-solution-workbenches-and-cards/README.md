## Variant: Interactive Solution Workbench & 3-Column Dispatches (005-interactive-solution-workbenches-and-cards)

### Design stance
An interactive, single-fold Workbench Console for Solutions paired with a clean 3-Column Dispatch card grid for Blog posts. Maximizes information density in minimum vertical scroll height.

### Choices made
- **Tabbed Interactive Solutions Workbench:** Replaces long repeating cards with an integrated console. Visitors select capabilities from the left rail (`Multi-Tenant SaaS`, `AI Automation`, `Mobile Engineering`) to inspect the architecture specs and delivery guarantees on the right.
- **Uniform 3-Column Blog Cards:** Displays recent technical dispatches with category tags, publication dates, and clean problem summaries in a balanced grid.
- **Strictly Grayscale:** Clean borders, monospaced metadata, and subtle hover lifts.

### Trade-offs
- Low vertical height preserves homepage rhythm, but requires user interaction (clicking tabs) to discover all 3 solutions.
- 3-column blog grid displays exactly 3 posts prominently; additional posts require a "View All Articles" navigation.
