## Variant: Interactive Systems Workbench & Inspector (011-work-interactive-workbench-matrix)

### Design stance
A split-screen, master-detail engineering workbench. Perfect for senior engineering managers, principal architects, and research directors who want an interactive, tactile experience inspecting deep architectural components without leaving the page.

### Key features
1. **Master Systems Rail (Left):** Dense, high-signal list of all production systems (`Hermes Agent`, `Afno Events`, `Syasyah Samaj`, `Nepse Pro`, `Astro Guru`, `Research Foundations`) with live active highlights and quick metrics.
2. **Sticky Live Inspector (Right):** Large, dedicated visual simulator stage showing the active system's interactive DAG/pipeline, deep architectural narrative, 3-column performance metrics, and immediate live/case study triggers.
3. **Zero Scrolling Fatigue:** The user selects projects from the left rail while the inspector updates dynamically in place, keeping the entire page within a single clean desktop viewport.
