## Variant: Two-Pane Systems Dossier & Interactive Role Inspector (008-about-two-pane-systems-dossier)

### Design stance
An executive-level technical dossier. Consolidates career metrics into an asymmetric sticky left rail, while allowing visitors to toggle between `Production History`, `Systems Architecture`, and `Academic Degrees & Research` without endless vertical scrolling.

### Choices made
- **Executive Metric Grid:** Quantifies impact upfront (`6+ YRS`, `10K+ Agent Tasks`, `3 PROD SaaS Platforms`, `2 Degrees`).
- **Interactive Multi-Tab Viewport:** Keeps total page height under 700px on desktop while maintaining comprehensive technical depth.
- **Strictly Grayscale:** Uses high-contrast neutral borders, monospaced metadata, and clean button actions.

### Trade-offs
- Tabbed navigation requires user clicks to discover all sections (not ideal for print/PDF export, but highly efficient for screen skimming).
