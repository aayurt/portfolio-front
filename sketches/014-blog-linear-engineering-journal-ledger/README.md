## Variant: Chronological Engineering Journal & Unified Timeline Ledger (014-blog-linear-engineering-journal-ledger)

### Design stance
An editorial chronological journal that organizes writings along a connected vertical timeline. Replaces the disconnected floating left date scrubber with an integrated narrative track.

### Visual elements & hierarchy
- Single-column high-legibility timeline
- Connected timeline rail with node markers
- Clean metadata (reading time, track badge, date)
- Focused typography without distracting media thumbnails

### Trade-offs
- Pure reading focus; lacks visual diagrams on the index page.
- Linear sequence does not separate doctoral research from devops tutorials.
