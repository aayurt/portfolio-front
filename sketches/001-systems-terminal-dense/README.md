## Variant: Systems Terminal Dense (001-systems-terminal-dense)

### Design stance
A high-density, engineering-centric command terminal that puts system architecture, live telemetry, and interactive pipeline DAGs above traditional biographical marketing.

### Key choices
- **Layout:** Asymmetric split-rail (Left: Fast-switch project matrix; Right: Active architecture DAG + live simulated telemetry console).
- **Typography:** High-legibility monospaced & technical sans-serif font stack.
- **Color:** Strict grayscale palette (#111, #333, #666, #ddd, #fafafa) with single heavy outlines denoting execution state.
- **Interaction:** One-click instant project switcher updating nodes, technical specs, and appending realistic telemetry log packets.

### Trade-offs
- **Strong at:** Immediately signaling deep systems proficiency, concurrency, multi-agent pipelines, and production reliability for technical recruiters and engineering directors.
- **Weak at:** Less conventional biographical storytelling or visual photography emphasis.

### Best for
- Staff / Principal Engineer roles, distributed systems jobs, and technical recruiters who want proof of architectural execution in the first 5 seconds.
