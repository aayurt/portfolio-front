## Variant: Interactive Systems Reader & Abstract Console (015-blog-split-console-and-abstract-reader)

### Design stance
An interactive split console that allows readers (academics, recruiters, engineers) to inspect papers and articles directly from the index. Selecting an item on the left reveals the full formal abstract, methodology outline, and table of contents on the right sticky stage.

### Visual elements & hierarchy
- Master list (left) with metadata and track indicators
- Pinned reader stage (right) with formal abstract, section table of contents, and read actions
- Dynamic client-side switching

### Trade-offs
- Highest density for skimmers; readers can evaluate all 6 publications without leaving the page.
- Requires desktop screen width for side-by-side console. Stacks on mobile.
