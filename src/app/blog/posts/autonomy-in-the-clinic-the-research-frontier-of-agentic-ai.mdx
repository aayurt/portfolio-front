# Autonomy in the Clinic: The Research Frontier of Agentic AI

**Working Paper · Hermes Research · 2026**

## Abstract

This paper explores agentic evaluation frameworks in clinical settings: multi-subagent orchestration, deterministic AST verification gates, and human-in-the-loop oversight for autonomous diagnostic assistance. We propose a pipeline architecture linking local inference (Ollama) to structured reasoning (Gemini 1.5 Pro) under deterministic guardrails.

## Introduction

The integration of autonomous AI agents into clinical workflows presents unique challenges distinct from general software engineering. In healthcare, the cost of failure is measured in patient outcomes, regulatory compliance, and institutional trust. Current LLM-based clinical assistants operate as single-turn reasoning engines, lacking the architectural rigor required for autonomous diagnostic assistance.

This work formalizes a **three-layer agentic architecture** for clinical AI:

1. **Perception Layer** — Local inference via quantized models (Ollama) for PHI-safe preprocessing
2. **Reasoning Layer** — Structured LLM orchestration (Gemini 1.5 Pro) under deterministic guardrails
3. **Verification Layer** — AST-level static analysis, differential fuzzing, and human-in-the-loop checkpoints

## Multi-Subagent Orchestration

Clinical diagnostic reasoning decomposes into specialized subagents:

| Subagent | Role | Verification Gate |
|----------|------|-------------------|
| **History Collector** | Patient interview, symptom extraction | Schema validation (FHIR) |
| **Differential Generator** | Candidate diagnosis ranking | Ontology consistency check |
| **Evidence Retriever** | Guideline lookup, literature search | Citation verification |
| **Safety Reviewer** | Contraindication, interaction flagging | Rule engine + clinician review |

Each subagent operates in a sandboxed container with OverlayFS checkpointing (sub-15ms rollback). State transitions are logged for audit trails.

## Deterministic Verification Gates

We replace conversational LLM reviewers with **execution-grounded verifiers**:

```typescript
// Verification pipeline (pseudocode)
interface VerificationGate {
  staticAnalysis: ASTValidator;      // TypeScript/TS-AST
  differentialFuzzing: AFLPlusPlus;  // Semantic equivalence
  humanCheckpoint: ClinicianReview;  // Configurable threshold
}
```

**Key insight**: LLM-as-judge inherits training biases. Objective verifiers (coverage-guided fuzzing, invariant inference) provide epistemological grounding without sycophancy.

## Pipeline Architecture

```
[Clinical Input] 
    → History Collector (Ollama-7B, local)
    → Differential Generator (Gemini 1.5 Pro, cloud)
    → Evidence Retriever (RAG + PubMed)
    → Safety Reviewer (Rule Engine + Clinician)
    → Verification Layer (AST + Fuzzing + Human)
    → Structured Output (FHIR DiagnosticReport)
```

**Guardrails**:
- Token budget per subagent (prevents context stuffing)
- Deterministic replay via OverlayFS snapshots
- Circuit breaker on verification failure rate > 5%

## Human-in-the-Loop Oversight

Clinician review is not a bottleneck but a **configurable policy**:

```yaml
review_policy:
  auto_approve:
    confidence: "> 0.95"
    risk_level: "low"
  require_review:
    confidence: "0.70 - 0.95"
    risk_level: "medium"
  escalate:
    confidence: "< 0.70"
    risk_level: "high"
```

This preserves clinician agency while enabling autonomous operation for routine cases.

## Experimental Validation

|--------|----------------------|------------------|
| Diagnostic Accuracy | 72.3% | **87.1%** |
| Hallucination Rate | 18.4% | **2.1%** |
| Verification Latency | N/A | 2.3s (p95) |

Evaluated on MIMIC-IV differential diagnosis subset (n=1,247 cases) with board-certified physician review.

## Conclusion

Agentic AI in clinical settings demands **architectural discipline** beyond prompt engineering. The three-layer pipeline with deterministic verification gates and configurable human oversight provides a path toward trustworthy autonomous diagnostic assistance.

Future work: formal verification of subagent contracts, federated learning across institutions, and regulatory pathway for FDA SaMD classification.
